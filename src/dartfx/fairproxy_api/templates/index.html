FAIRification Proxy API

Exposing unified metadata profiles and dataset structures across heterogeneous data catalogs via semantically enriched, structured schema standards.

Interactive Swagger UI ReDoc Reference API Health Status

Supported Metadata Profiles

DCAT-3 RDF
W3C vocabulary for cataloging datasets, enabling federated metadata harvesting.
ML Croissant JSON-LD
MLCommons format optimizing metadata exchange for machine learning applications.
DDI Codebook XML
XML profile standard for documenting social science surveys, study structures, and codebooks.
DDI-CDI RDF
Cross-Domain Integration model for detailing granular column variables and integration mappings.
Postman JSON
Instantly importable collections enabling rapid local API exploration and testing.
Markdown TEXT
A human-readable data summary document detailing columns, descriptions, and servers.

API Endpoint Directory

Method Endpoint Path Description
GET /status Returns the overall operational status and version of the API.
GET /servers Retrieves all data host servers registered in the configuration registry.
GET /datasets/{uri}/{format} Unified endpoint to fetch metadata for a dataset URI in a specified format (dcat, croissant, ddi/codebook, ddi/cdi, markdown, postman/collection, native).
GET /socrata/{host}/{dataset_id}/{format} Socrata platform-specific proxy endpoint to bypass URI decoding and query raw hosts.
